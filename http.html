HTTP is the foundation of communication on the World Wide Web. It defines how messages are formatted and transmitted between a client (browser) and a server.

How it works

  • The browser sends a request (e.g., open a webpage).
  • The server processes the request.
  • The server sends back a response (HTML page, data, etc.).

Key point

HTTP is stateless — each request is independent. The server does not remember previous requests.
